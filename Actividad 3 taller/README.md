El proyecto consiste en una aplicación de carrito de ventas desarrollada en Angular. Permite visualizar productos, agregarlos al carrito, modificar sus cantidades y eliminarlos. Para compartir y actualizar el estado del carrito entre componentes se utilizó un servicio con BehaviorSubject y Observables, permitiendo una actualización reactiva de la información. Además, se implementaron pipes personalizados para calcular los subtotales de cada producto y el total general. Se utilizaron directivas como *ngFor y *ngIf, junto con data binding, para mostrar dinámicamente la información. El proyecto demuestra el uso de componentes, servicios, Observables y pipes en una aplicación funcional.  :D
